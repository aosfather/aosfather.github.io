Music Engine · MCP + CLI

一个播放器，
接住所有音乐与所有 AI 助手

mygod 运行在你自己的电脑上：把多个在线曲库和本地音乐库合成同一个播放队列， 再以「智能助手接入」和「命令行」两种方式对外开放。一句话放歌，一条命令接管播放状态。

FEATURES

为“听歌”这件事做减法

不用在几个客户端之间来回切换，也不用为了放一首歌去学一套新接口。

◎

多源聚合检索

一次搜索看到多个在线曲库与本地库的结果，每条都标明来源与可播状态，不用逐平台试听。

✦

助手原生接入

以标准 MCP 服务（stdio 类型）暴露能力，Trae、Codex、WorkBuddy 等支持 MCP 的助手配置一行路径即可使用。

◫

单一播放器，多端共享

本机只允许一个播放实例；多个助手或终端同时连接，读写同一份队列、进度与音量，不会互相打断。

⌂

本地音乐库

登记一个目录，自动建立索引并支持增量重扫；本地文件直接读取播放，不复制、不转码、不上传。

♫

音质与音效

标准 / 较高 / 极高 / 无损四档自动向下兼容；均衡器预设、夜间模式、增强、响度均衡均随会话保存。

会话恢复与自愈

退出后按上次队列与进度恢复；不可播的曲目自动跳过，取流 15 秒无数据即判定失败，不让播放在加载里卡死。

INSTALL

安装：三分钟，两个可执行文件

mygod 不依赖任何后台服务：所有数据（会话、索引、缓存）都在你自己的电脑上。

取得两个可执行文件

mygod-mcp —— 给支持 MCP 的智能助手用；mygod-cli —— 给命令行与脚本用。

目标平台：macOS（Apple Silicon）。两个文件彼此独立，用哪一个就装哪一个，也可以两个都装。

放进 PATH，并赋予执行权限

# 放到个人 bin 目录（若目录不存在先创建）
mkdir -p ~/.local/bin
mv mygod-mcp mygod-cli ~/.local/bin/
chmod +x ~/.local/bin/mygod-mcp ~/.local/bin/mygod-cli

# 确认 PATH 里有它（zsh 用户写进 ~/.zshrc）
export PATH="$HOME/.local/bin:$PATH"

如果你的文件在别处，后面所有配置里把 /Users/you/.local/bin 换成实际目录即可。

验证安装

# 命令行：应打印引擎版本、可用来源与登录状态
mygod-cli status

# 助手接入端：应输出 MCP 握手信息后等待标准输入
mygod-mcp

首次跑起来会自动创建一个常驻引擎；之后无论从哪个入口连接，用的都是同一个播放实例。

数据都在本机。 播放会话、本地索引、缓存文件统一保存在 ~/.local/share/mygod；除向你自己指定的曲库来源取流外，不向任何第三方发送播放数据。
MCP SERVER

接入智能助手：把路径告诉它，剩下的它自己配

mygod-mcp 是一个本地 stdio 类型的 MCP 服务：不需要端口、不需要服务器、不需要网络权限，助手用它就像读一个本地工具。

它是什么类型

项值说明
传输类型stdio通过标准输入 / 标准输出与助手通信，本机进程间对话
启动方式由助手拉起助手启动时按配置执行该路径，随用随起
参数无空参数数组即可；常驻引擎由它自己管理
并发多客户端安全多助手同时连接不会互相抢播放器，后到者接入同一实例

方式一：让助手自己完成配置（推荐）

在对话里直接对助手说下面这句话，它会自行写入 MCP 配置并完成握手验证：

TRAE

“帮我加一个 MCP 服务器，名字叫 mygod，类型 stdio，命令路径是 /Users/you/.local/bin/mygod-mcp，不需要参数，加好后调用一次 status 验证。”

CODEX

“在 MCP 配置里增加 mygod：stdio 类型，command 为 /Users/you/.local/bin/mygod-mcp，无 args，然后跑一次工具列表确认能看到 scan_local。”

WORKBUDDY

“接入本地 MCP 服务 mygod，类型 stdio，可执行文件在 /Users/you/.local/bin/mygod-mcp，配置完读一次播放状态。”

路径改成你自己的实际位置即可；换成任何支持 MCP 的助手，说法都通用。

方式二：手工写入配置

通用 mcpServers 写法（Trae 等使用 JSON 配置的助手）：

{
  "mcpServers": {
    "mygod": {
      "type": "stdio",
      "command": "/Users/you/.local/bin/mygod-mcp",
      "args": []
    }
  }
}

使用 TOML 配置的助手（如 Codex）：

[mcp_servers.mygod]
command = "/Users/you/.local/bin/mygod-mcp"
args = []
配好之后能做什么？ 助手可以检索与播放、控制队列（上一首 / 下一首 / 暂停 / 跳转 / 音量）、 读歌词与评论、看发现页与电台、调节音效、登记本地音乐目录、读取当前播放快照——共 19 个能力动作，语义与命令行完全一致。
COMMAND LINE

不支持 MCP？用命令行，一样能把播放管起来

任何终端、脚本、快捷键工具、定时任务都可以调用 mygod-cli；输出是结构化的，便于下游程序解析。

命令一览（mygod-cli help 的完整版）

mygod-cli — 音乐引擎的命令行形态

  status                        引擎版本、可用来源、登录状态
  search <关键词> [--kind k] [--source s] [--limit n]
  play <关键词> [--source s] [--n i] [--yes]
       play --tracks id,id | --playlist id | --album id | --radio mode
  state                         当前播放与接下来播放
  next | prev | pause | toggle | resume | radio_exit
  volume <0-1> | eq <preset> | repeat <off|all|one> | shuffle [on|off]
  lyrics [id] [--source s]      不传 id 则取正在播放的那首
  catalog <kind> <id> [--source s] [--tab t] [--limit n] [--offset n]
  discovery <kind> [--source s] [--limit n]
  radio [mode]                  个人电台（default / familiar / explore）
  login-qr                      扫码登录（需要登录的来源）
  help                          显示本帮助

  sources: 运行 status 查看当前可用的来源标识（默认使用第一个）
  无参数启动时进入交互模式；退出交互不影响已建立的播放

命令说明

命令作用关键参数
status查看引擎版本、可用来源与各来源登录状态—
search按关键词检索，只返回结果不播放--kind 结果类型；--source 来源；--limit 条数
play检索并播放，或用编号 / 歌单 / 专辑 / 电台直接建队列--n 播第几条；--yes 跳过确认；--tracks / --playlist / --album / --radio
state当前曲目、进度、队列、音量、循环与随机—
next / prev切到下一首 / 上一首—
pause / resume / toggle暂停、继续、在两者间切换—
radio_exit退出电台续播，队列不再自动延长—
volume设置音量，跨接入端共享0-1 之间的浮点数
eq切换均衡器预设，flat 关闭预设名
repeat循环模式：关闭 / 列表 / 单曲off | all | one
shuffle随机开关，不带参数即开启on | off
lyrics取时间轴 / 翻译 / 逐字歌词id 曲目编号；--source 来源
catalog打开艺人、专辑、歌单或用户页kind 与 id；--tab、--limit、--offset
discovery发现页：每日推荐、推荐歌单、精选、榜单、最近播放kind；--limit
radio按口味生成连续曲目default / familiar / explore
login-qr扫码登录需要账号的来源，凭据保存在本机—
help打印命令表—

常用示例

# 搜一下，看看有哪些可播的版本
mygod-cli search "晚风" --limit 10

# 直接播搜索结果里的第 2 条
mygod-cli play "晚风" --n 2 --yes

# 用一组曲目编号建队列，从第 1 条开始
mygod-cli play --tracks 1001,1002,1003

# 打开一个歌单并整体入队
mygod-cli play --playlist 7788

# 列表循环 + 随机，然后把音量调到 60%
mygod-cli repeat all && mygod-cli shuffle on && mygod-cli volume 0.6

# 看现在在放什么
mygod-cli state
让不支持 MCP 的助手也能用： 你不需要额外封装，只要告诉它“用 shell 调用 mygod-cli，先跑 help 看命令表”，它就能自己选命令、读输出、决定下一步。
FAQ

常见问题

同时开几个助手，会不会有两个播放器在放？

不会。mygod 在本机只允许一个播放实例：先连上的持有引擎，其余的以客户端身份接入，读写同一份队列与进度。任一入口切歌，其他入口的下一次快照就同步更新。

必须登录吗？

不必。部分曲库来源对游客开放检索与播放，受限能力会在检索阶段就标注出来，不会等到点了播放才失败。需要更多能力时用 mygod-cli login-qr 扫码，凭据只保存在本机。

本地音乐怎么用？

两条路：助手侧调用 scan_local 的 add 登记目录并建立索引，之后本地文件与在线曲目一样可被搜索；不接助手时，也可以直接用命令行播放已知路径，例如 mygod-cli play --tracks /Users/you/Music/a.mp3 --source local。文件不会被复制或转码。

数据存在哪里？怎么清空？

统一在 ~/.local/share/mygod：播放会话、本地索引、缓存。删掉这个目录等同于恢复出厂；删除缓存子目录只影响已缓存曲目，不影响索引与队列。

播放卡在加载怎么办？

不会一直卡住。取流 15 秒没有新数据即判定该曲目失败并自动跳到下一首；整条队列都不可播时停在停止态并给出原因，不会无限重试。

能不能下载歌曲？

不能，也不提供。mygod 只做在线取流播放和读取你本机已有的文件；不提供下载、转存或再分发能力。
